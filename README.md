# Credit Card Fraud Detection System

![Power BI Dashboard Screenshot](images/powerbi_screenshot.png) *(Replace with your actual screenshot)*

## 📌 Project Overview
Machine learning model to detect fraudulent transactions with:
- **Jupyter Notebook** for model development
- **PostgreSQL** for data storage
- **Power BI** for visualization

## 🛠️ Technologies Used
| Technology | Purpose |
|------------|---------|
| Python (Pandas, Scikit-learn) | Data processing & ML model |
| Jupyter Notebook | Development environment |
| PostgreSQL | Database storage |
| Power BI | Dashboard visualization |
